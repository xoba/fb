# PDF

fb displays PDFs with WebKit's built-in viewer.

**Extensions:** `.pdf`

## What you see

The document itself, scrollable and with selectable text where the file has it. The PDF fills
the window, so there is no **raw** link: **File > Print…** prints it, and **File > Save a
Copy…** saves the original.

## Options

PDFs are binary, so they ignore [links to lines](../linking.md#links-to-lines).

## Limits and fallbacks

fb sets no size limit on PDFs.
