# Keyboard shortcuts

## Files and windows

| Keys | Command |
|------|---------|
| ⌘N | New fb window |
| ⌘O | Open a file or folder |
| ⇧⌘S | Save a copy of the original file |
| ⇧⌘R | Reveal the current file in Finder |
| ⌘P | Print, or save as PDF from the print dialog |
| ⌘W | Close the window |
| ⌘Q | Quit fb |

## Moving around

| Keys | Command |
|------|---------|
| ⌘\[ | Back |
| ⌘\] | Forward |
| ⌘R | Reload the page |

You can also swipe left or right with two fingers to go back and forward.

## Finding text

| Keys | Command |
|------|---------|
| ⌘F | Find in this page |
| Return or ⌘G | Next match |
| ⇧⌘G | Previous match |
| Esc | Close the search field |

## Zoom

| Keys | Command |
|------|---------|
| ⌘+ | Zoom in |
| ⌘- | Zoom out |
| ⌘0 | Actual size |

## Help

| Keys | Command |
|------|---------|
| ⌘? | Open fb Help |
