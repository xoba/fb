# fb Help

fb is a read-only file browser for your Mac. It shows Markdown, office documents,
notebooks, source code, email, calendars, spreadsheets, databases, images, audio,
video, and archives in a form meant for reading. Everything happens on your Mac, and
your original files are never changed.

These pages are ordinary Markdown files inside the app, displayed by fb the same way
it displays your own. To search them, type in the search field at the top of the
**Help** menu.
