# File catalog

A tiny in-memory catalog of example files.

| Name | Bytes |
|------|------:|
| `notes.md` | 120 |
| `letter.eml` | 240 |

## Labels

- **notes.md**: 120 bytes
- *letter.eml*: 240 bytes

Browse them with `fb`; see [the examples](https://example.com/examples).

> Labels are printed, never written back.
